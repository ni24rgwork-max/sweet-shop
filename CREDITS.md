# Asset provenance

The MIT licence in [LICENSE](LICENSE) covers the source in this repository.
This file records where the bundled artwork came from.

## Originated for this project

| File | Notes |
|---|---|
| `logo.png` | Wordmark, set in Georgia Bold |
| `profile-image.png` | Monogram avatar — deliberately not a photograph of a real person |
| `Special offer 1–4.png` | Headline, sub-line and discount badge composited over the CC0 photographs listed below |

Category glyphs and all interface icons are drawn from
[Material Symbols](https://fonts.google.com/icons) via `material_symbols_icons`
(Apache 2.0), not from bundled artwork.
